# Agent Rules

## Git Workflow
- Do NOT automatically commit or push any changes to any git branch (`git add`, `git commit`, `git push`).
- Leave all modified and newly created files UNCOMMITTED in the working directory.
- Only run `git commit` or `git push` when the user explicitly instructs with "commit this" or "push this".
- At the end of each task, report the list of changed files and state that they are ready for the user to review and commit manually.
